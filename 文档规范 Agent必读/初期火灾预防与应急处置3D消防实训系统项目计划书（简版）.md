# 初期火灾预防与应急处置3D消防实训系统项目计划书

## 一、项目定位

开发一套结合**3D虚拟场景、消防知识教学和实体消防实训设备**的消防培训软件。

培训内容围绕初期火灾全过程展开：

初起火灾应对 → 灭火器扑救 → 火势扩大后的安全逃生。**

培训时由一名学员代表操作软件和实训设备，其他学员共同观看并参与答题。

---

## 二、培训模式

采用：

**一名学员代表操作 + 全体学员共同参与答题。**

代表学员负责：

- 控制3D人物；
- 场景观察和交互；
- 执行火灾处置任务；
- 操作实体模拟灭火器。

全体学员共同参与：

- 消防隐患判断；
- 火情判断；
- 灭火方式选择；
- 逃生路线判断；
- 消防知识问答。

一期人物操作采用：

**键盘 + 鼠标。**

后续可扩展游戏手柄、身体转向识别和VR。

---

## 三、关卡设计

一个3D场景划分为多个相互独立的培训关卡。

一期设置三个主要关卡：


### 第一关：初起火灾应对

模拟火灾刚刚发生。

学员需要判断：

- 火灾类型；
- 第一处置措施；
- 是否需要断电；
- 是否具备扑救条件；
- 应选择何种灭火方式。

重点训练火灾发生后的判断和初期处置能力。

### 第二关：灭火器扑救

结合：

- 模拟灭火器；
- 模拟火箱。

由代表学员进行实体灭火操作，系统读取设备状态，并根据操作结果控制3D火焰及模拟火箱反馈。

重点训练正确的灭火器操作和初起火灾扑救。

### 第三关：火势扩大与逃生

模拟火势已经超出安全扑救范围。

学员需要：

- 判断停止扑救时机；
- 选择正确逃生路线；
- 避开火焰及浓烟区域；
- 到达安全区域。

重点训练火势失控后的安全撤离能力。

## 四、三关流程（依据最新实施文档）


每题/每阶段的固定顺序：

```
情景动画（默认 6 秒，不计时）
  → 答题 / 操作（只有这一段消耗时间：第一关每题 15 秒、第二关操作 60 秒、第三关撤离 90 秒）
  → 解说 + 正确答案 + 用户答案 + 正确操作示范（默认 6 秒）
  → 【等待继续：不自动推进】
  → 鼠标点击「继续」才进入下一步
```

- 解说、等待继续、暂停期间：**火灾模拟与考试计时都冻结**，没有隐藏的继续计时。
- 可以**重播**情景动画与示范；重播不改变题目答案。
- 超时**也要**出解说、正确答案与示范，不会跳过。
- 分数用 0—100 分制，**60 分是达标线**；分数与结果分开呈现。

### 4.2 第一关：初起火灾应对（30 分）

四题，固定顺序，**每题 7.5 分**，**至少 3 题正确**才算通过；答错只让该题 0 分，不抹除已得题分。

1. 报警示警
2. 识别带电火灾 Class C
3. 由获授权人员安全断电（不得接近起火插头）
4. 判断是否具备初期扑救条件

（原第五题已从第一关删除。美国口径：报警 911，火灾分类 A/B/C/D/K，带电设备为 **Class C**，不使用 E。）

### 4.3 第二关：灭火器扑救（45 分）

```
器材选择题（5 分，同样：情景动画 → 15 秒 → 解说 → 点击继续）
  → 器材准备页（此时计时与火焰都还没启动）
  → 点击「开始操作」才启动 60 秒计时 + 火焰模拟
```

- 器材题题意：办公区可能涉及带电设备及纸张 → 选 **ABC 多用途干粉**；干扰项：仅 A 水型、仅 D 金属专用。
- 60 秒是**操作总上限**，失控可提前终止。
- 操作条目：器材检查（必做，不单独计分）+ 拔销 5 + 瞄准 10 + 压把 10 + 扫射 10 + 扑灭且观察 5 秒 5。
- 正确覆盖可以灭火；**只喷上方无效**；局部压制会留下余火并**复燃**；不随机制造事故。
- 注意：**不继承**上一题错误作为触电惩罚，也不把「未断电冷却系数 ×0.2」当成物理规律。

### 4.4 第三关：独立失控情景撤离（25 分）

- 显式说明这是**独立失控情景训练**，不会因为第二关灭火成功就变成失败。
- 90 秒撤离，路线：两排工位间出生 → 避开西侧火源附近的近路 → 沿排间通道**向东** → 经**中右工位组间南下** → **南走廊** → **接待区** → **双开门** → **出口外安全区**。
- 轻度受烟影响区**要求低姿**；**浓烟封锁区蹲下也过不去**，必须绕行。
- 正确绕行、后退**不扣分**；**取物才记错**。
- 计分：10 秒内撤离 3 + 低姿/完全避烟 5 + 不取物 5 + 到安全区 12。超时或在危险区失败**不授予**到达分。
- 不会随机封死唯一有效路线；未做真实建筑疏散合规认证，这是有确定可用路线的教学情景。

### 4.5 结算

- 每关结束都显示结果与教官总结；**失败不中断培训**。
- 第二关或第三关未通过时显示「安全操作待复训」，**不能**只用总分宣称全部合格。
- 结算保存本地报告并提供返回主菜单。

## 五、场景设计方式

采用：

**一个3D场景 + 多个关卡状态。**

例如同一个办公室场景分别加载：

1. 消防隐患状态；
2. 初起火灾状态；
3. 灭火实训状态；
4. 火势扩大及逃生状态。

各关卡之间相互独立。

上一关是否成功，不改变下一关能否开始。

例如第一关没有发现某个消防隐患，第二关依然按照预设的“初起火灾状态”正常开始。

这样既保证教学流程完整，也方便对每一个培训阶段进行独立设计和评分。

## 六、技术方案

### 3D资源制作

采用：

**Blender**

负责场景、消防设施、道具、材质及模型优化。

### 软件开发

采用：

**Unity + C# + URP**

主要负责：

- 3D场景；
- 键盘鼠标人物控制；
- 关卡系统；
- 倒计时系统；
- 任务系统；
- 问答系统；
- 火灾状态；
- 火焰及烟雾效果；
- 设备通信；
- 成绩统计。

---

## 九、实体设备

一期接入：

**模拟灭火器 + 模拟火箱。**

基本流程：

**模拟灭火器操作 → Unity读取设备数据 → 判断灭火效果 → 控制3D火焰 / 模拟火箱反馈。**

软件设置独立设备接口，方便未来更换设备或增加新的消防训练硬件。

一期完成：

- 1个3D消防培训场景；
- 4个消防培训关卡；
- 键盘鼠标控制；
- 限时任务系统；
- 自动关卡推进；
- 消防隐患排查；
- 初起火灾处置；
- 模拟灭火器实训；
- 模拟火箱联动；
- 火势扩大及逃生；

- 评分系统；
- 本地成绩保存；

暂不开发：

- 云服务器；
- Web管理后台；
- 手机独立答题；
- 游戏手柄；
- 身体追踪；
- VR；
- 多人联网。

---

## 十二、一期目标

一期重点完成一套完整且不中断的消防培训流程：

**隐患排查 → 初起火灾 → 灭火扑救 → 火势扩大 → 安全逃生。**

每一个关卡均设置时间限制。

**成功获得分数，失败或超时记录结果但不阻断培训，所有学员最终都会完成完整消防培训流程。**

通过这种方式，使系统同时具备：

**教学过程完整性 + 操作考核能力 + 成绩区分能力。**
