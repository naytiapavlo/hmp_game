## 二、怎么进第二关

**从主菜单（正式路径）**：初始界面 → `Start Training` → 选关窗口出现两张卡 `OFFICE` / `EXTINGUISHER` → 点 `EXTINGUISHER` → `Start Training` → 直接加载第三场景（第二关没有配 CG 转场，走加载页直进）。

**编辑器直开（开发调试）**：打开 `Assets/Scenes/第三场景.unity` → Play。`autoStart=true` 后行为与从主菜单进入一致（架构文档 §二 的口径）。

进关后的 Console 指纹：

```text
[LevelBoot] 关卡就绪：level_2_extinguisher_fire（灭火器扑救）　阶段 1 段　火势 cue 5 条
[LevelFlow] 开局：level_2_extinguisher_fire　入口=主菜单选场景 / 直接 Play 场景（开发/验收）
[LevelFlow] 阶段 1/1 → free_roam_extinguish（灭火器操作（自由练习）／freeRoam）
[LevelFlow] [火势] 灭火器操作（自由练习） → Small（cue fire_initial，实例 已生成）
[LevelFlow] 相机转向起火点 …
```

## 三、第二关当前配置为什么只有一段

```json
{ "id": "free_roam_extinguish", "kind": "freeRoam",
  "duration": 0.0, "timed": false,
  "fireCue": "fire_initial", "playerControl": true, "frameFire": true, "freezeFire": false }
```

- **`duration 0` + `timed false`** ＝ 不启倒计时、不因超时推进 → 这一关现在就是**自由练习**：
  玩家可自由走动、拿灭火器、按住左键喷射压制火焰，`FireSuppression` 的降级/复燃/扑灭确认、5 秒观察窗全部照常工作。
- **`frameFire true`** ＝ 进关瞬间把玩家相机转向起火点（与第一关失火动画同一入口），一进 Play 就看得见火。
- **F10**（`LevelFlowRunner.debugKeys`）跳过本阶段 → 流程正常收尾（`Finish()`：隐藏加载遮罩、交还操控），不会卡住。
- 进关时 `QuizLoadingOverlay` 会在拿到操控的那一刻自动淡出（见第一节第 7 项）；之后全程可见可操作。
- 计划书 §4.3 的正式流程（器材选择题 5 分 → 器材准备页 → 点「开始操作」启 60 秒 + 火焰 → 拔销/瞄准/压把/扫射/扑灭计分）
  **尚未实现**：等做第二关内容时，把 stages 换成 `quiz → freeRoam` 并给 freeRoam 段填 `duration: 60 / timed: true` 即可，
  **不需要改任何代码**（计分接口见下）。

已就绪、等接进计分的第二关接口（全部来自灭火器喷射链路，无需新增）：

| 接口 | 用途 |
|---|---|
| `ExtinguisherSpray.PinPulled / PullPin()` | 拔销步骤（5 分）。当前 `pinPulled` 恒 true 占位 |
| `ExtinguisherSpray.SpraySecondsTotal / SweepAngleTotal` | 喷射时长 / 水平扫角累计（扫射 10 分） |
| `FireSuppression.LevelLowered / Reignited / Extinguished` | 降级链、复燃、扑灭且观察 5 秒（5 分）的事件 |
| `FireEffectController.SetLevel / SetFrozen` | 火势分级与冻结（引擎已是唯一权威下发方） |

## 四、以后加关卡＝零代码

《关卡架构设计（骨架版）》§二 的三步，现在**三步全部真的零代码**（第 3 步以前是空的，本轮补上）：

1. 做关卡场景，放 `LevelBootstrapper`（含 `锚点_出生点` 子物体）；
2. 写 `Resources/Configs/Levels/level_xxx.json`；
3. `levels.json` 的 `levels` 数组加一条 → **选关窗口自动多一张卡**，`Start Training` 直接进关。

卡片按 `status` 渲染三态：`available` 可选、`locked`（配 `unlockAfter`）与 `comingSoon` 不可选并置灰。
卡片文案与切图也在注册表里：`cardTitle` / `cardDescription` / `cardImage`（`cardImage` 是 **Resources 下的 Sprite 路径**；
留空则克隆卡不显示预览图——等美术给某关的卡图，把图放进 `Assets/Resources/` 再填一行即可，仍然不用改代码）。

> 主菜单视觉是英文，所以第一关的卡片文案由注册表显式写着 `OFFICE / Office fire safety training`——
> 与协作者交付的预制体文字逐字一致；中文 `displayName`（初起火灾应对）只用于日志与关卡内部。

## 五、`SceneSelectUI` 改动清单（**需同步给协作者**）

《关卡架构设计（骨架版）》§五 要求「实施时需把改动清单同步给协作者（SceneSelectUI 属其维护模块）」：

1. **视觉资产零改动**：`Assets/UI/SceneSelection/SceneSelectionUI.prefab`、`MenuButtonGraphic` 样式、卡片尺寸 464×478、
   间距与章节排布、`Editor/SceneSelectionUISetup.cs` **都没有改**。第一张卡直接复用摆好的 `officeCard`，
   其余卡片运行时 `Instantiate` 克隆它；两张静态 `ComingSoon1/2` 占位卡被 `SetActive(false)`（**没有删**，仍在预制体里）。
2. **序列化字段**：新增 `cardSpacing`（默认 500，与 58/558/1058 排布一致）；**删除** `officeScenePath`
   （路径改由构建列表按 `sceneName` 反查，顺带把「场景没进构建列表」变成明确报错）。其余字段全部保留。
3. **`SelectOffice()` 保留**：预制体里 `officeCard.onClick` 那条持久监听仍指向它（避免「丢失方法」告警），
   现等价于 `Select(0)`。运行时 `Bind()` 会把每张卡（含模板卡）的 `onClick` **按索引重接**——
   否则克隆卡会复制同一条持久监听，点哪张都去选第一关。改的是运行时场景实例，预制体资产不受影响。
4. **进关逻辑**：`LoadOffice()` → `LoadLevel(LevelEntry)`。CG 转场只在关卡配了 `transitionVideo` 时启用
   （第二关无 CG，走 `QuizLoadingOverlay` + 加载页直进）；`OfficeFireChoiceFlow.RequestOnNextOfficeLoad()`
   改由「关卡配置里是否含 `quiz` 段」判定（不写死关卡 id）。加载页那两个写死的 `OFFICE` 文案
   （大标题 + `Loading …%`）也改成按所选关卡显示；第一关卡title 就是 `OFFICE`，视觉不变。
5. 既有自动验收 `Editor/QuizLoadingChecks.cs`（走 `menu.StartTraining()` → `SelectOffice()` → `StartSelectedScene()`）
   **语义未变，仍应全绿**。

## 八、验收步骤

1. 打开 Unity → 等自动编译结束 → 看 Console 与本报告 `Library/Level2Setup.txt` 是否 `SUCCESS`；
2. 菜单 `Tools/Level2/检查第二关接入`：构建列表应含第三场景且 enabled，`levels.json` 应列出 2 条，
   第二关阶段应为 `1 段 [freeRoam]`；
3. 初始界面 Play → `Start Training`：选关窗口应有 `OFFICE` 与 `EXTINGUISHER` 两张可选卡（不再有 COMING SOON），
   点第二张 → 徽标与 `Selected: EXTINGUISHER` 正常 → `Start Training` → 进第三场景；
4. 进关后：相机自动转向起火点、火为小火、可自由行走；E 拿起灭火器、左键喷根部能压制/降级/复燃/扑灭；
5. 回归第一关：选 `OFFICE` → 起火 CG 照常 → 三题流程与结算不受影响；
6. Console 不应出现 `[LevelFlow] 配置里找不到 cue`、`[SceneSelect] 关卡场景不在构建列表里`、`[LevelBoot] 找不到出生点锚点`。
