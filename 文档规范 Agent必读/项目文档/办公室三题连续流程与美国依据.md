# 办公室三题连续流程与美国依据

2026-09-21，在第一关现有题目后增加两轮完整流程。保留俯视四选一、跟随路线、对准本次目标按 E、Correct / Incorrect、教官三句话、第二句话后的视频槽位。每题独立限时 45 秒；选择及到达不算完成，交互前超时按错误处理。

## 内容与依据

| 顺序 | 题目 ID | 情境 | 正确行动／场景交互 |
| --- | --- | --- | --- |
| 1 | `office_fire_first_action` | 发现插排冒烟 | 原有报警选项／入口门 |
| 2 | `office_fire_no_extinguisher` | 设备仍带电、无合适灭火器、他人已获警示、出口畅通 | 撤离并在室外拨打 911／入口门 |
| 3 | `office_damaged_strip` | 消防人员确认可进入，电源已隔离，插排已冷却但明显受损 | 停用并报告安全更换／受损插排 |

第二题参考 [USFA《Choosing and Using Fire Extinguishers》](https://www.usfa.fema.gov/prevention/home-fires/prepare-for-fire/fire-extinguishers/) 和 [OSHA 灭火器基础指导](https://www.osha.gov/etools/evacuation-plans-procedures/emergency-standards/portable-extinguishers/about)：不具备安全扑救条件时撤离；带电电气设备适用 Class C 级灭火介质，不用水代替灭火器。没有把“无灭火器也必须扑灭”设为标准动作。错误选项为取文件、开窗及接近起火插头。教官解释正确做法及这些选择为何不能替代安全撤离。

第三题依据 [OSHA 29 CFR 1910.334(a)(2)(ii)](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.334) 及 [OSHA Electrical Safety 指导](https://www.osha.gov/etools/hospitals/hospital-wide-hazards/electrical-safety)：可能造成伤害的受损电气设备应退出使用，必要修理与测试确认安全后才可复用。仅仅冷却、散烟或接上打印机“试一试”不能作为安全确认；电气测试由合格人员执行。进入本题时火势为 None，题干明确安全前提，避免暗示玩家在火场主动接近带电受损设备。

这些是按美国联邦机构公开指导／条文编写的训练情境；USFA 指导与 OSHA 强制条文在来源中分别标明，不代表整个产品已取得美国认证。检索日期为 2026-09-21，来源链接也随题目保存在 JSON 的 `sources` 中。题目和台词沿用现有英文界面及字体。

## 运行与配置

题库仍为 `HMP_game/Assets/StreamingAssets/Quiz/scene_choices.json`。每道实体交互题增加：

- `correctOptionId`：当前题目的唯一正确选项，不再用一个门或插排的固定答案覆盖所有题。
- 选项的 `interactionTargetId`：绑定现有四个物体，分别为 `rescue_documents`（打印机）、`open_window`（窗）、`raise_alarm`（门）、`unplug_strip`（插排）。这些是稳定的场景绑定 ID，实际答案 ID 可按题变化。
- `interactionPrompt`、`routeLabel`：本题的 E 交互提示与路线文字。
- `timeLimitSeconds`、`instructor.correct/incorrect.first/second/third`、`instructor.videoPath`：沿用已有配置。
- `sources`：标题、原始链接和检索日期，便于复核教学内容。

新增科普视频路径分别为 `Videos/office_fire_no_extinguisher.mp4` 和 `Videos/office_damaged_strip.mp4`，相对于 StreamingAssets。当前尚未提供这两个视频文件，保留已有的缺文件提示和继续至第三句流程；未把起火 CG 冒充科普视频。

关卡阶段在 `Assets/Resources/Configs/Levels/level_1_initial_fire.json` 中按三组 `quiz → freeRoam → result` 排列。新增 `StageDto.questionId` 决定当前题；第二、三题通过 `resetPlayerToSpawn` 回到练习起点，避免前一题站在门边导致下一题无需跟随路线。必须关闭本题教官第三句才会继续下一题。

第二题正确撤离后的过渡不把火焰熄灭，避免暗示“离开＝灭火”；第三题代表消防处置后的新阶段，显式切为无火。移除原来独立的空科普等待阶段，科普槽位随各题教官流程走。当前实际题目总数更新为 3，保留每题 7.5 分、至少 3 题正确的原有配置，当前三题满分为 22.5 分；后续新增题目时可继续调整关卡计分参数。

`OfficeFireChoiceFlow` 缓存原始场景绑定，并按当前题构造选项→路线映射。`OfficeChoiceInteraction` 按本题答案判定并更新提示。`LevelFlowRunner` 逐题记录真实题 ID、选项 ID、用时及超时状态。原先示例题库条目保持不变。
