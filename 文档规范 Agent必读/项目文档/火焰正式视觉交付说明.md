# 火焰正式视觉交付说明

## 交付内容

`模型/火焰.blend` 保留 Mantaflow 火焰与烟雾的控制器、气体域、燃料发射体和体积材质。协作者补交的 `mantaflow-cache.zip` 已验证可读，包含 72 帧 `data` 与 72 帧 `noise` 缓存；它只用于重新渲染，不作为 Unity 运行时依赖。

Unity 运行时使用从模拟渲染出的 8×8、64 帧透明图集：

- `Assets/VFX/T_Fire_Small_8x8.png`
- `Assets/VFX/T_Fire_Medium_8x8.png`
- `Assets/VFX/T_Fire_Large_8x8.png`
- `Assets/VFX/T_Smoke_Small_8x8.png`
- `Assets/VFX/T_Smoke_Medium_8x8.png`
- `Assets/VFX/T_Smoke_Large_8x8.png`
- `Assets/VFX/T_Smoke_SmokeOnly_8x8.png`

`SG_FireFlipbook.shadergraph` 与 `SG_SmokeFlipbook.shadergraph` 通过 `FireFlipbook.hlsl` 完成帧插值、UV 湍流扰动、透明边缘软化和深度交界淡出。`FireVisualUpgrade` 会在 Unity 导入图集后替换四个预制体的粒子材质，保留 `FireVfx` 与 `FireEffectController` 的四参数接口。

## 重新生成

需要 Blender 5.2 或兼容版本。先把缓存目录放到 `模型/火焰制作/` 的工作目录，再执行：

```text
blender --background --factory-startup --disable-autoexec 火焰.blend --python 模型/火焰制作/bake_fire.py -- --tier Small --output <output>
blender --background --factory-startup --disable-autoexec --python 模型/火焰制作/render_fire.py -- --bake <output>/Small --size 128 --engine BLENDER_EEVEE
python 模型/火焰制作/pack_atlases.py --bakes <output> --output HMP_game/Assets/VFX
```

四档大小沿用源文件控制器预设：`0.12 / 1.0 / 2.5` 分别对应 Small、Medium、Large；SmokeOnly 使用 Small 的模拟尺寸并关闭火焰场。

## 验收

打开办公室场景，确认 Console 没有 `HMProtection/ParticleFx` Shader 错误。运行 `Tools → Fire → Install Baked Visuals`（首次导入图集会自动尝试），Play 后在起火点按 F9 检查 `None → SmokeOnly → Small → Medium → Large`。第一人称与俯视相机都要确认火舌、烟柱、暖光和暂停冻结正常。

图集来源为项目自有 Blender 模拟与项目内缓存；没有引入第三方视觉资产。
