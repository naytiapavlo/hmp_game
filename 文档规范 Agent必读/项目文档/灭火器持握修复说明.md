# 灭火器持握修复说明

日期：2026-09-22

## 问题与根因

实际日志中的旧对齐结果为 Euler (-25.440, -44.032, -85.337)，对应瓶身相对持握框架倾斜 85.79°。
旧 SolveHoldAlignment 把提把和收纳状态的喷嘴当成刚性双点，通过旋转整个瓶身去贴两只手。
模型软管没有随拿取形变，因而左右手约束反过来把瓶子横转。这不是模型必须横拿。

## 实现

- ExtinguisherCarryRig 保持瓶身世界直立，按真实网格中心对齐提把与右手抓握点。
- NozzleBody 独立对齐左手，出口朝向视线。原 Hose 网格复制后用三次曲线变形连接，不修改导入模型；这是几何变形而非软体物理模拟。
- 放下或禁用时还原喷嘴与软管，销毁时释放网格副本。模型导入开启 Read/Write。
- 删除 F11 / 拾取时整瓶刚体求解；喷射从真实 Nozzle 发出，LateUpdate 排在持握更新之后。
- ExtinguisherSetup 和第三场景同步关闭整瓶俯仰、清零旋转偏移，原抓取、喷射和压制链路保留。

## 验证证据与边界

1. 历史日志回放稳定重现 85.79° 倾斜（15° 阈值失败）。
2. Unity 6000.6.0f1 隔离项目加载真实 FBX 与生产 ExtinguisherCarryRig，60 组转身/俯仰/双手间距组合全部通过：瓶身直立、两手位置接触、喷口方向、软管顶点有限、恢复/再次应用姿态、原网格未变。
3. 实际项目全部运行时 C# 与 Editor C# 编译通过，仅存在已有的过时 API / 未使用字段警告。

隔离检查的玩家组件使用最小夹具，直接调用生产 ApplyPose；它不等于运行完整第三场景。
尚未完成现场 Play 视觉验收：腕指朝向、软管局部外观/穿插、第一人称遮挡、E/Q 物理释放和喷射手感。
不据数学位置测试宣称整套拿取动画已视觉验收。

## 项目内复验

退出 Play 等待脚本和模型重新导入，再进入第三场景拿起灭火器，无需重跑场景装配。
菜单 Tools → Props → 验收：灭火器直立持握与软管 会在临时预览场景检查真实模型，结果写到 Library/ExtinguisherCarryChecks.txt。
手动查看平视/抬头/低头/转身时瓶身直立、右手提把、左手握喷嘴，放下后收纳姿态恢复；再次拿起并喷射确认出粉位置。

## 后续：过高占屏与摄像机裁切修复

用户反馈直立后仍高举遮挡、镜头进入模型。新增摄像机回归检查先在旧实现失败：真实 FBX 底圈在俯仰测试中深度仅 0.08294m，小于第三场景 nearClipPlane=0.3m。

- 前臂从右 +15° / 左 +25° 下调到右 -18° / 左 -8°，同步组件默认值、装配常量和第三场景序列化值。
- 每帧以真实网格包围盒（含弯曲软管、喷嘴）与双掌余量计算摄像机空间校正；模型顶部限制在 viewport y≤0.40，最近深度至少 max(0.45m, nearClipPlane+0.10m)。
- 通过 ArmsPitchFollow.ShiftHeldPose 同时移动整个手臂与持物，再更新两手接触。仅持灭火器时应用；每帧从手臂原始基准重算，放下后恢复，无累计偏移。
- 未缩小模型、未更改摄像机近裁剪面，也未改水杯等物品姿势。
- 同一隔离 Unity 回归由 FAIL 转 PASS：60 组姿态全部满足裁切距离、下方占屏、无校正漂移、瓶身直立和双手位置接触。运行时与 Editor 编译通过；完整游戏画面的实际手指/遮挡观感仍需 Play 确认。

## 后续：平视过低修正（取代上一节的单向下压规则）

旧规则只限制最高位置而不会抬起已经过低的道具。新增平视可见性检查重现：提把 viewport y=0.059，几乎落到屏幕底部。
现在以提把 viewport y=0.34 为目标做双向高度调整，同时将几何/掌面顶部限制在 y=0.48 以下；近裁剪安全距离保持不变。
双手与瓶身一起移动，原前臂参数不再反复抬高/降低。平视时提把应处于下方约三分之一处，上半瓶身可见。
180 组转身、俯仰、手距及高低起始手位检查通过，包括平视提把 y 在 0.24–0.38、无裁切、无位置累计漂移和双手接触；运行时与编辑器编译通过。现场画面仍以 Play 验收为准。

## 后续：真实相机层级与俯仰修复（当前规则）

前两轮的 180 组检查只覆盖单位缩放摄像机和假定的左右抓握点，未覆盖实际手臂与相机层级。真实第三场景 body 缩放 (0.5,1,0.5)，相机局部缩放 (0.7272,0.3636,0.7272)；旋转后不能把 Transform.InverseTransformPoint 当作渲染视图坐标。
新增真实 FPHands 预制体及相机层级回归，旧版在低头 35° 测到提把 viewport y=-0.1572（出屏）；抬头 -30° 的手臂网格曾进入近裁剪面。

当前修复：

- ExtinguisherCarryRig 用 camera.worldToCameraMatrix / cameraToWorldMatrix 求投影与位移，消除相机/父级缩放干扰。
- ArmsPitchFollow.PrepareExtinguisherPose 仅在持灭火器时以摄像机完整旋转摆手臂，避免死区/部分俯仰和世界下沉叠加；专用根旋转 -55°，不改其他持物的跟随参数。
- 左右前臂当前均为 -18°，减少喷嘴与提把的高差。取消假想手掌顶部 10cm 对可见高度的压制，仍保留近裁剪距离余量。
- 提把固定在 viewport y=0.30。大俯仰角下若瓶身超过顶部限制，整套持握沿视线前移以满足限制，不再将提把往屏幕外压。瓶身仍然保持世界直立。

验证：运行时与 Editor 编译通过；原 180 组回归通过；真实手臂/相机 9 个俯仰角 (-80,-60,-30,0,20,35,50,70,80) 全通过，提把高度均为 0.3000，手臂网格最近深度至少 0.4906m（近裁剪 0.3m）；重复帧无位置累积，放下后恢复普通手臂基准。另渲染检查平视、低头 35° 和抬头 60° 的模型预览。

新增菜单：Tools → Props → 验收：灭火器真实手臂与相机俯仰，报告 Library/ExtinguisherViewChecks.txt。
蒙皮检查使用 BakeMesh(mesh,true) 补偿 renderer 缩放后变换到世界坐标，依据 Unity 6000.6 BakeMesh API：https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/skinnedmeshrenderer/bakemesh 。
隔离预览使用诊断纯色材质，验证姿态和遮挡，不代表第三场景最终光照/贴图；未代替完整场景 Play 操作验收。
