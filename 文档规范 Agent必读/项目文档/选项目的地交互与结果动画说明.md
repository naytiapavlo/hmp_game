## 复用反馈动画

共用 Prefab：`Assets/UI/QuizFeedback/QuizResultFeedback.prefab`。

将它放到其他场景，引用 `HMProtection.Quiz.QuizResultFeedback`，调用：

```csharp
feedback.Show(true);                              // Correct
feedback.Show(false);                             // Incorrect
feedback.Show(true, "Great work! Keep going.");   // 自定义副文案
feedback.Dismiss();                               // 关闭并恢复
```

`ShowCorrect()` / `ShowIncorrect()` 无参数入口可直接连 Inspector 的 UnityEvent。重复 Show 在展示期间返回 false。`onPresented(bool)` 在开始展示时触发；`onDismissed` 在关闭后触发。动画使用 unscaledDeltaTime，不依赖全局时间缩放。

Prefab 自带 CanvasScaler、TMP 文本、遮罩、按钮和动画图形。没有 EventSystem 时按需创建 Input System UI EventSystem；也可指定场景现有备用 EventSystem。`blackoutDuration` 默认 0.3 秒，`animationDuration` 默认 1.65 秒。不要把其他流程的逻辑写进动画组件，使用上述事件衔接。

物体的结果由 `OfficeChoiceTarget.correct` 配置；目标 ID 对应题库选项 ID。办公室当前明确规定第 3 项正确，因此 `Assets/Resources/Configs/Levels/level_1_initial_fire.json` 的 `correctOptionId` 同步设为 `raise_alarm`。之后改答案时应同时调整这两处。
