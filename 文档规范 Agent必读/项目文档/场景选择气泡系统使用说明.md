## 在 Unity 中预览

1. 打开 `Assets/Scenes/办公室场景.unity`，进入 Play。
2. 打开 `Tools > Scene Choices > Preview & Validate`。
3. 点击 `2 options`、`4 options` 或 `6 options`。点击选择框后，窗口显示结果，其他选项锁定。
4. 修改 JSON 后点 `Reload JSON & Preview`。窗口提示框重叠或目标超出相机等问题。
5. 点击 `Exit Overview / Restore Player` 恢复第一人称。关闭预览窗口也会退出。

挂载入口：`Tools > Scene Choices > Install in Office`。已有系统时不会重复创建。保存场景后再使用。测试入口：`Tools > Scene Choices > Run Play Mode Checks`，运行检查并留下六选项预览；报告 `Library/SceneChoiceImageChecks.json`，此文件是本机临时测试报告，不作为工程资产。

## 题库与锚点

题库位于 `Assets/StreamingAssets/Quiz/scene_choices.json`，一个文件多道题。正式题号 `office_fire_first_action` 和示例题号 `office_choose_2/4/6` 共用同一 Prefab。数量由 options 长度决定，默认序号 A/B/C；题目设置 `numberedOptions: true` 时使用 1/2/3/4。label 为英文，prompt 可空。

```json
{
  "version": 1,
  "questions": [{
    "id": "my_question",
    "prompt": "Where would you go?",
    "options": [{
      "id": "exit",
      "label": "Exit",
      "target": {"mode": "anchor", "anchorId": "office.exit", "offset": [0, 0.15, 0]},
      "bubbleOffset": [-180, 120],
      "width": 300
    }]
  }]
}
```

| 参数 | 含义 |
|---|---|
| target.mode | anchor 或 position |
| anchorId | 场景中 SceneChoiceAnchor 的唯一编号 |
| target.position | position 模式必填 [世界 X,Y,Z] |
| target.offset | 世界坐标偏移，可省略 |
| bubbleOffset | 1920×1080 基准 UI 单位，X 向右、Y 向上；默认 [-180,120] |
| width | 默认 300，允许 240–800；字体保持 24，长文字换行增加高度 |

已有锚点：office.exit、office.reception、office.manager、office.pantry、office.workstation、office.lounge。增加地点时，在目标下创建空物体，挂 `SceneChoiceAnchor`、填写唯一 anchorId，并将空物体移到希望尾尖指向的位置。同一锚点可跨题重复使用，移动父物体会自动跟随。

按原图尾巴方向，推荐将文字框放在目标上方，避免极端偏移让尾巴穿过主体。框体限制在画面边界内；不自动重排。超出相机或在相机后面的目标会隐藏其框，并在预览中提示。

## 接入其他流程

命名空间 `HMProtection.Quiz`，在流程组件中引用场景内 `SceneChoicePresenter`：

```csharp
void OnEnable() { presenter.SelectionSubmitted += OnChoice; }
void OnDisable() { presenter.SelectionSubmitted -= OnChoice; presenter.ExitOverview(); }
void BeginQuestion(string id)
{
    if (presenter.EnterOverview() && !presenter.ShowQuestion(id))
        Debug.LogError(presenter.LastError);
}
void OnChoice(SceneChoiceResult result)
{
    // result.questionId / optionId / targetMode / anchorId / worldPosition
    // 外部在此决定反馈、下一题或 presenter.ExitOverview()。
}
```

亦可使用 Inspector 中 onSelectionSubmitted/onDisplayFailed。ShowQuestion 返回 bool；错误信息在 LastError，DisplayFailed 事件通知调用方。配置无效、缺少或重复锚点时整题拒绝显示。选择只提交一次，换题重新解锁；HideQuestion 回收气泡但保持俯视。ExitOverview 恢复进入前相机、监听器、人物/天花板可见性、控制和鼠标状态。组件被禁用时同样恢复。
