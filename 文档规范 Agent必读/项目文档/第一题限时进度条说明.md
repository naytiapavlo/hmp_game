# 第一题限时进度条

第一关 `office_fire_first_action` 从俯视选择题可交互时开始计时，选择选项、回到第一人称、沿路线行走以及抵达目标均不会停表。只有对本次选中的物体执行 E 交互才停止；时间耗尽直接显示 Incorrect，随后沿用错误分支的教官讲解。

## 配置与视觉

题库 `HMP_game/Assets/StreamingAssets/Quiz/scene_choices.json` 在第一题增加 `"timeLimitSeconds": 45`。单位为秒，当前默认 45 秒；改动此字段即可调整下一次出题时的限时。字段缺省或为 0 时使用场景 QuizTimerHUD 的默认秒数，负数与非有限数值会被题库校验拒绝。

屏幕底部使用提供的 `ui/通用/进度条.png` 作为轨道，红色填充随已用时间向右增长。`ui/通用/火焰图标.png` 跟随红色末端；每经过 1/3（15 秒）增加一枚火焰，与最初的火焰一起移动。新增图标向左错开并略微抬高，相互重叠遮挡，最初的火焰位于最前层；经过 2/3 后形成三枚一起移动的火焰簇。达到 3/3 立即切换错误结果。右侧显示分:秒倒计时，最后 10 秒变红。

资源副本位于 `Assets/UI/QuizTimer/`，原图保持不变。轨道副本裁掉大面积透明边缘以适配 UI，使用 CanvasScaler 跟随分辨率缩放；UI 不接收射线，不遮挡选项或物体交互。

## 实现与复用

- `QuizTimerHUD` 订阅 `QuestionPresented` / `QuestionCancelled`，以真实时间持续计时，独立于旧关卡阶段时限；取消题目、完成交互和禁用组件时收起 UI。
- `OfficeChoiceInteraction` 接收单次 `TimedOut` 事件，取消仍打开的俯视题目、撤销路线与目标交互并打开 Incorrect。E 交互入口再次检查截止时间，防止脚本 Update 的执行顺序让逾期交互算作成功。
- `LevelFlowRunner` 在物体交互或超时时才记录实体题得分，用时包含行走。选中正确选项但来不及操作会记录 `timedOut=true`、错误得分并进入错误火势结果。反馈和教官讲解期间保持原有冻结／等待行为。
- `QuizTimerSetup` 在办公室场景装配 `Scene Choices/Quiz Timer Canvas` 并保存引用；菜单 `Tools > Scene Choices > Install Quiz Timer` 可重新装配。
