## 一、已完成事项

### 1. 场景物体批量添加碰撞体

- 给「场景」空物体下所有**有网格的子级**（共 765 个，SCN_Office_01 实例）添加了非凸静态 `MeshCollider`；
- 16 个纯组织节点（GRP_ 分组等，无网格）按设计跳过，避免产生巨大隐形碰撞体；
- 采用 MeshCollider 而非 BoxCollider 的原因：初版第一人称近距离行走，盒碰撞体在家具周围会形成"隐形方墙"；
- 性能评估：全静态 + 仅玩家一个动态查询方，每帧物理开销远低于 1ms；后续可按需削减（天花板 134 个碰撞体玩家碰不到，可优先砍）。

### 2. 第一人称玩家控制（body 脚本）

- 实现 WASD 行走、鼠标转视角（水平转身转 body，俯仰只转眼睛相机 ±85° 限位）、重力与落地贴合；
- 总开关 `controlEnabled`（默认开）：关闭后停止操控并自动释放鼠标光标；
- 输入基于新版 Input System 直接轮询（工程为 Input System Only，旧版 Input 不可用）；
- 自动挂载脚本已完成场景配置：CharacterController（height 1.8 / radius 0.3，胶囊覆盖地板到 1.81m，眼高 1.56m，符合规范约 1.6m 要求）、相机引用已接 Main Camera；
- 顺带清理了实验遗留：body 上重复的 body 组件、误挂到 FPHands 左臂骨骼上的 body 组件及其残留 CharacterController、占位 CapsuleCollider（会挡交互射线）。

### 3. 移动参数调整

- 行走速度从 3 调整为 **1.4 m/s**（正常成年人步行速度），脚本默认值与场景序列化值均已同步；
- 新增 **按住 Ctrl（左右均可）跑步**，默认 5 m/s，松开恢复步行；斜向限速对两档速度同样生效。

### 4. 天花板统一显隐开关

- 新增 `CeilingVisibility` 组件挂「场景」根物体，统一控制 134 块 `SM_Ceiling_*` 的可见性；
- 编辑模式即时生效（ExecuteAlways），无需进 Play；
- 边沿触发设计：只在总开关变化时统一下发，隐藏全部后仍可单独勾选某块的 MeshRenderer 单独显示；
- 代码接口 `SetCeilingsVisible(bool)` 供后续 UI / 教学流程调用；
- 用途：培训/讲解时隐藏天花板俯视房间内部与起火点。

### 5. 人物统一显隐开关

- 新增通用组件 `VisibilityToggle`（挂在哪个物体就控制其整个子层级）挂「人物」根物体；
- 一次开关覆盖人物全部 3 个渲染体：身体胶囊 MeshRenderer ×1 + 双手 SkinnedMeshRenderer ×2；
- 人物隐藏后第一人称视角与移动不受影响（相机不是渲染体），可用于截图或旁观视角；
- 同样支持单独覆盖、代码接口 `SetVisible(bool)`、右键菜单「重新收集目标」。

## 三、测试方法

1. Play 模式：WASD 行走（1.4 m/s），按住 Ctrl 跑步（5 m/s），鼠标转视角；Inspector 取消勾选 `controlEnabled` 立即停控并释放光标；
2. 隐藏天花板：选中「场景」取消 `Ceilings Visible`，Scene/Game 视图 134 块天花板整体消失，可单块恢复；
3. 隐藏人物：选中「人物」取消 `Visible`，身体与双手整体消失，视角与移动照常。

## 四、已知问题与后续事项

- **FPHands 不跟随俯仰**：双手挂在 body 下，跟随水平转身但不跟随低头/抬头；做手部动画时移到 Main Camera 下或由动画控制；
- **场景级碰撞 vs 预制体**：碰撞体以场景实例覆盖形式存在，`SCN_Office_01.prefab` 资源本身没有；新场景重拖预制体后需跑 Tools/Scene/Re-run Collider Setup；
- **天花板开关不含灯具**：`SM_LightPanel`（灯板）、`SM_HVAC_Diffuser`（风口）不在 `SM_Ceiling` 前缀内，隐藏天花板时仍可见；如需联动再扩展前缀列表；
- **性能优化留待 Profile 后**：天花板碰撞体（134 个，玩家碰不到）、方盒类家具可换 BoxCollider；现阶段正确性优先；
