# 选择题后教官讲解

第一关三道题共用讲解流程：选择目标并完成 E 交互 → Correct / Incorrect 动画 → 点击结果页 Continue → 教官第一句 → 任意键 → 第二句 → 任意键 → 播放科普视频 → 第三句 → 任意键 → 下一题或后续关卡。超时也进入 incorrect 对话。

界面保留左侧电视、右侧教官布局，底部使用 `ui/关卡/9f79e531-08e3-4dcd-ac1a-5ddb6093131d.png` 的完整红边对话框和 HAIMO 名牌。沿用现有英文界面，教官页不再显示 Next 等按钮，右下角提示任意键推进；键盘、鼠标按键和手柄按钮均可使用，鼠标移动不触发。每一步需要松开按键后重新按下，带短暂输入保护，防止打开页面的按键穿透或长按跳句。视频正常结束自动进入第三句，也可按任意键跳过。

整体使用深色渐变背景、统一正文与辅助文字层级，进入、换句和退出采用短暂淡入淡出及轻微位移动画。正文完整显示，不等待逐字播放。动画使用独立于关卡暂停的时间；讲解中屏蔽关卡调试快捷键，避免任意键意外跳关或解冻火势。结果页原有 Continue 按钮保留。

## 配置

统一编辑 `HMP_game/Assets/StreamingAssets/Quiz/scene_choices.json` 的对应题目：

```json
"instructor": {
  "enabled": true,
  "speaker": "INSTRUCTOR",
  "videoPath": "Videos/office_fire_first_action.mp4",
  "correct": {
    "first": "正确时第一句话",
    "second": "正确时第二句话",
    "third": "正确时第三句话"
  },
  "incorrect": {
    "first": "错误时第一句话",
    "second": "错误时第二句话",
    "third": "错误时第三句话"
  }
}
```

以上中文用于解释字段，当前实际文案为英文。现有字体为 LiberationSans SDF；若正式文案改中文，需配置覆盖所需中文字形的 TMP 字体。

`videoPath` 相对于 `Assets/StreamingAssets/`。正式视频放到 `HMP_game/Assets/StreamingAssets/Videos/office_fire_first_action.mp4`，也可修改字段指向其他相对路径、绝对路径或 HTTP(S) URL。优先使用构建时随包分发的相对路径。

目前尚未提供科普视频文件。没有把起火 CG 当成正式科普内容。文件未提供、解码失败或准备/播放停滞时，电视显示视频不可用提示，按任意键后进入第三句，流程不会卡住。第二句以前不会请求/播放视频。

`enabled` 为可选功能开关。其他示例题没有启用讲解，保持原有行为；启用后必须同时配置正确、错误分支的三句话，题库加载时检查完整性。

## 实现与复用

- `InstructorLessonView.cs`：可复用运行时 UI、视频与对话状态机。`Show(config, correct)` 打开，`Dismiss()` 关闭，`Closed` 通知关闭。重复 Show 不会重入。
- `InstructorLessonLayout.cs`：16:9 安全区域等比缩放，适配宽屏和较窄画面。
- `OfficeChoiceInteraction.cs`：按实际反馈结果选 correct/incorrect；结果 Continue 后打开讲解，末句关闭后恢复本组件施加的暂停。运行时自动添加组件，不需要重新安装或手工接场景引用。
- `LevelFlowRunner.cs`：等待结果与教官讲解全部关闭再离开行走阶段；俯视期间超时也先等待讲解。讲解期间冻结火势及关卡计时。
- `SceneChoiceCatalog.cs`：同一 JSON 的 DTO 与校验。
- `InstructorBackdropGraphic.cs`：代码绘制的深色渐变背景。
- 资源：`Assets/Resources/InstructorLesson/`。电视来自 `ui/通用/`；对话框复制自上述 `ui/关卡/` 新素材，保持原图比例和完整 UV；教官为原人物透明底副本。原资源未覆盖。JSON 的 `speaker` 保留为配置字段，当前视觉名牌使用素材自带的 HAIMO。

Unity 菜单 `Tools > Scene Choices > Check Instructor Lesson` 可运行 Play 模式集成检查。报告 `Library/InstructorLessonChecks.txt`，截图 `Library/Instructor-correct.png`、`Instructor-incorrect.png`、`Instructor-video.png`。检查使用现有起火 MP4 作为临时解码样本，仅修改内存配置，不覆盖题库；检查后退出 Play 并恢复原编辑场景。当前场景有未保存更改时检查会停止，先保存后重试。

原有 `OfficeChoiceActionChecks` 和 `QuizTimerChecks` 已更新为识别结果后的教官界面，它们仍分别负责真实 E/Enter 输入链路和倒计时回归。
