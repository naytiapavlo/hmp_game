# 选择题加载过渡

第一关在 CG 开始前先显示章节标题页：`LEVEL 1` / `EARLY-STAGE FIRE`。页面沿用深色渐变、红色点缀，顶部使用用户提供的透明白色 logo（`Resources/Branding/ChapterLogo.png`），淡入 0.35 秒、完整停留 2 秒、淡出 0.35 秒后自动播放 CG。标题显示期间视频尚未开始准备或播放，不消耗答题倒计时；取消进入关卡时同步清理标题页。

CG 播放结束或跳过后显示加载页，直到俯视镜头、题目和四个选项准备完成再淡出。教官最后一句继续时，加载页先出现在教官页面下方，覆盖退出动画和下一题前的结果阶段，避免中间露出无法操作的第一人称画面。

加载页沿用深色渐变和红色进度条，显示准备状态与百分比。首次进入包含场景加载、原有失火原因阶段、俯视镜头和选项准备；题目之间包含结果阶段、出生点重置、镜头和选项准备。后续题目复用同一个办公室场景，百分比表示整个过渡的阶段进度，不是磁盘读取百分比。保留 JSON 的原有阶段时长与火势变化，不额外添加长时间等待。

只有加载页到达 100% 并完成短暂淡出后，`OfficeFireChoiceFlow.QuestionPresented` 才触发：选项开始响应、45 秒计时开始。加载时鼠标点击由画布遮挡，场景 E/Q 交互及 F8/F9/F10 调试键不可用。停止关卡或取消尚在准备的题目会清除加载页，避免计时或出题协程稍后重新出现。

## 实现

- `Assets/scripts/UI/QuizLoadingOverlay.cs`：可跨场景的运行时加载页，`Show`、`SetProgress`、`Reveal`、`Hide`。加载画布层级 31090，位于教官画布下方、玩法 UI 上方；不依赖手工接线或修改场景。
- `Assets/scripts/UI/LevelChapterCard.cs`：在现有 CG 画布内创建章节标题、logo 和自适应布局；`CgTransitionPlayer.chapterHoldSeconds` 控制完整停留时长。
- `CgTransitionPlayer`：CG 结束时显示加载页并隐藏原黑场，场景激活后销毁 CG 对象；加载页继续存活，避免与关卡等待 CG 对象销毁的逻辑互相等待。
- `LevelFlowRunner`：首段、题间结果阶段推进进度；`PrepareNextQuizTransition` 仅在后续还有选择题时接管教官退场。
- `InstructorLessonView.Closing` 与 `OfficeChoiceInteraction`：退出动画前建立加载背景，关闭回调提供同步兜底。
- `OfficeFireChoiceFlow`：在遮罩下准备俯视、气泡布局，加载完成后才启用题目及倒计时。
