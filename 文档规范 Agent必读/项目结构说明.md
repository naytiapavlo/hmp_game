## 几点说明

- **工程入口**：Unity 版本 6000.6.0f1（URP + Input System Only），用 Unity Hub 打开 `HMP_game/`。
- **代码现状**：目前只有第一人称玩家控制与「天花板 / 人物」显隐两类脚本，配套 4 个 Editor 一次性装配工具（运行结果写入 `Library/*.json`，不入库）；关卡、任务、问答、评分、火灾状态、设备通信等系统尚未开始。
- **美术管线**：`模型/` 存放 Blender 源与交付件，`HMP_game/Assets/` 存放 Unity 侧成品（FBX + 材质 + 贴图 + Prefab），命名遵循 `SM_`（模型）/`MAT_`（材质）/`T_`（贴图）规范。
- **大文件**：`*.blend`、`*.fbx`、`*.psd` 由 Git LFS 管理，新增二进制资源前先确认扩展名已被 `.gitattributes` 覆盖。
- **文档落点**：项目相关文档统一放在 `文档规范 Agent必读/项目文档/`，规范类文档放在 `文档规范 Agent必读/` 根下。
