# 科普视频

第一关三题分别预留独立的教官讲解视频：

- `office_fire_first_action.mp4`：最初发现火情。
- `office_fire_no_extinguisher.mp4`：没有合适灭火器时撤离；带电设备不可用水扑救。
- `office_damaged_strip.mp4`：确认安全后将受损电气设备停用并报告。

视频目前尚未提供。将 MP4 放到本目录即可使用；或修改 `../Quiz/scene_choices.json` 中对应题目的 `instructor.videoPath`。路径相对于 StreamingAssets。播放顺序为第一句、第二句、视频、第三句。

视频缺失或播放失败时可继续到第三句，不会卡住训练。
